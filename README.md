# AI Habit Tracker Pro

An AI-powered habit tracking application built with Flask, SQLite, Gemini AI, and Matplotlib.

## Features

* ✅ Add and manage daily habits
* 🔥 Streak tracking system
* 📊 Habit analytics dashboard
* 📈 Progress charts
* 🤖 AI Habit Coach using Gemini AI
* 🏅 Achievement badges
* 📄 PDF progress reports
* 🌙 Modern dark-mode interface
* 💾 SQLite database storage

## Tech Stack

* Python
* Flask
* SQLite
* Google Gemini AI
* Matplotlib
* ReportLab
* HTML
* CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/minnie703/AI-Habit-Tracker-Pro.git
cd AI-Habit-Tracker-Pro
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
